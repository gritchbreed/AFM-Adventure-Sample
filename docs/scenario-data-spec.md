# 台本のデータの形（spec_version 1）

`UI/UI/Resources/scenario.json` の形です。エンジン（`Yukemuri/Sources/YukemuriEngine/Scenario.swift`）はこの形だけを読みます。台本を直したら `yukemuri validate` で確かめてください。

## 最上位

| キー | 内容 |
| --- | --- |
| `spec_version` | 1 |
| `protagonist` | 主人公。`name`（名前。台詞の `{名前}` に入る）と `rules`（自由会話の「守ること」に入れる、主人公の扱い） |
| `partner` | 相棒の人物 ID（相棒のいる場面で、いつも一緒にいる） |
| `place_aliases` | 場所の別の呼び方（`{"控え室": ["控室", "奥"]}`）。移動の言い方の判定と、解釈の選択肢の説明に使う |
| `intents` | 意図（話題）。下の表 |
| `persons` | 人物。下の表 |
| `scenes` | 場面。最初の場面から始まる |

## intents

| キー | 内容 |
| --- | --- |
| `id` | 意図の ID（条件の `意図:ID` で使う） |
| `description` | 解釈の選択肢の説明（モデルが読む） |
| `examples` | 発言例（モデルが読む。発言例とほぼ同じ文は、規則でその意図にする） |
| `words` | 含む語（任意）。どれも含まない発言は、この意図にしない |

## persons

| キー | 内容 |
| --- | --- |
| `id` | 人物 ID |
| `speaker_name` | 名札とプロンプトに出す名前（ママ、葵） |
| `profile` / `personality` | 表の顔・人となり（プロンプトにそのまま入る文） |
| `speech` | 話し方：`first_person`（一人称。生成した台詞の検査に使う）、`items`（`name`・`value`）、`examples`（`input`・`reply`） |
| `knowledge` | 知っていること・考え：`info` と `condition`（任意）。条件がなければいつも、`意図:` を含む条件なら、その意図の入力のときだけプロンプトに入る |
| `fallbacks` | 台詞の生成が2回とも通らなかったときの台詞：`id`・`text`・`condition`（任意）。一巡するまで同じものは使わない |
| `calls_protagonist` | 主人公の呼び方（`{名前}さん`、`あなた`）。二人称なら、生成した台詞のほかの二人称を置き換える |
| `color` | 名札の色（紫、桃、青、緑、橙、赤） |
| `sprite` | 人物の絵の ID（`CH09` なら `CH09_normal.png` など） |

## scenes

| キー | 内容 |
| --- | --- |
| `id` / `title` | 場面の ID と、舞台の上に出す名前 |
| `place` | 場所（移動の行き先の名前） |
| `background` | 背景の絵の ID |
| `person` | その場にいる人物（相棒は含めない。いなければ省く） |
| `partner` | 相棒がいるか（省くと true） |
| `can_enter` | 行ける条件（任意） |
| `free_talk` | 自由会話の指示（人物 ID → その人物のプロンプトに入る文の配列） |
| `expressions` | 場面に入ったときの表情（人物 ID → 表情） |
| `lines` | 定型文。表の順が、選ぶ順番の基準になる |

### 定型文

| キー | 内容 |
| --- | --- |
| `id` | 定型文の ID（台本の中で重ならないこと） |
| `speaker` | 台詞の話者の人物 ID（省くと地の文） |
| `condition` | 条件（下の書き方） |
| `effects` | 効果の配列（下の書き方） |
| `repeatable` | 何度でも出るか（省くと false） |
| `no_ack` | この行そのものがプレイヤーへの返事なので、前に短い返事をはさまない |
| `variants` | 言い換え（2回目以降に出すときの文面。一巡したら元に戻る） |
| `text` | 文面。`{名前}` は主人公の名前に置き換える |

## 条件の書き方

`+` は「かつ」、`/` は「または」（`+` のほうが先に結びつく）、`!` は否定、`( )` でまとめる。

| 書き方 | 意味 |
| --- | --- |
| `常に` | いつも |
| `初回` | 初めてこの場面に入ったとき |
| `開始` | この場面に入るたび |
| `済:ID` | その定型文が出た |
| `場所:名前` | 今いる場所 |
| `フラグ:名前` | 効果でフラグが立った |
| `直後:ID` | その定型文のすぐ後（続けて出す） |
| `直前:ID` | その定型文のすぐ前（先に出す） |
| `次:ID` | その定型文の後の、次の入力（入力の中身を問わない） |
| `往復:ID:n` / `往復:場面:n` | その定型文（場面の始まり）から n 回入力した |
| `意図:ID` | 入力がその意図に当たった |
| `移動:場所` | 入力がその場所への移動に当たった |
| `離脱` | 入力が、その場を離れる言葉に当たった（行き先の一覧を出す） |

## 定型文の選び方

1回の入力で、エンジンは次の順に行を選ぶ。

1. 入力の条件（`意図:`・`移動:`・`離脱`・`次:`）を含む行のうち、条件を満たす最初の1行を出す
2. 入力の条件を含まない行を、表の順にすべて出す（`直前:`・`直後:` の行は、その行の前後に続けて出す）。別の場所へ移る入力のときは出さない
3. 移動・離脱の入力なら、場面を移る・行き先の一覧を出す
4. 当たる行がなければ、その場の人物の自由会話にする

## 効果の書き方

| 書き方 | 意味 |
| --- | --- |
| `フラグ:名前` | フラグを立てる |
| `登場:人物` / `退場:人物` | 人物が場に現れる・去る（場面を移ると元に戻る） |
| `揺らす:人物` | 人物の絵を揺らす |
| `動かす:人物:左` | 人物の絵の位置を変える（左・中央・右） |
| `表情:人物:笑顔` | 人物の表情を変える（通常・不安・笑顔・怒り・悲しみ。次の入力で元に戻る） |
